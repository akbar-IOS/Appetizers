# Appetizers

Production-style iOS application built with SwiftUI using MVVM architecture, async/await networking, dependency injection, singleton pattern, environment objects, and image caching.

## Features
- SwiftUI UI Development
- MVVM Architecture
- REST API Integration
- Async/Await Networking
- Dependency Injection
- Singleton Pattern
- Environment Objects
- AppStorage
- AsyncImage
- Remote Image Downloading
- Image Caching with NSCache
- Error Handling & Alerts
- Loading States
- Form Validation
- Regex Validation
- FocusState Keyboard Handling
- TabView Badge Support
- Clean Project Organization
- Data Flow Management
- iOS 15 & iOS 17 Features

## Technologies
- Swift
- SwiftUI
- URLSession
- Codable
- NSCache
- Async/Await
- ObservableObject
- @EnvironmentObject
- @AppStorage
- @Observable

## Architecture Concepts
- Dependency Injection
- Singleton Design Pattern
- State Management
- Data Flow
- ViewModels
- Network Layer Separation
